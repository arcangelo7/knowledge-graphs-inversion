## What does it do?

[R2RML](https://www.w3.org/TR/r2rml/) transforms relational databases into RDF graphs. This tool does the opposite: given an RDF graph and the R2RML mapping that produced it, it reconstructs the original relational data.

The tool reads an R2RML mapping document, generates SPARQL queries that reverse each mapping rule, and executes them against the RDF graph (N-Triples or N-Quads). The query results are then written back as SQL statements that reconstruct the original database tables.
